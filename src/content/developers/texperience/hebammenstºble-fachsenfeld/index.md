Interactive website of freelance midwife Hanna Rieber.

This site provides detailed information about services and features an integrated course management app. Courses are comfortably user-maintained through every Google calendar user interfaces. Attendees can self-register using the intuitive webforms, while all data is dynamically synchronised using the google-api-python-client package and a custom implementation of the business logic.
