GS worked with Pretzilla to develop a new and dynamic website to effectively engage and inspire customers. The website was built using Wagtail, an open source CMS built on the Django framework that allows for flexibility in development and design while providing an easy-to-use CMS for the client. The beautiful design showcases some seriously mouth-watering photos that have us inspired to grab a few pretzel rolls for lunch!
